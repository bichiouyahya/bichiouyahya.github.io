Hey, I'm **Yahya Bichiou**. I break web applications and write up how I did it.

This site is my lab notebook: CTF solves, OWASP Juice Shop challenges, and notes
on web exploitation — broken authentication, injection, access control, and
whatever else I manage to bend out of shape. Every writeup aims to show the full
path: the recon, the request that mattered, and *why* the bug exists.

## What you'll find here

- **Writeups** — step-by-step exploitation of real challenges and labs.
- **Notes** — techniques, payloads, and methodology I keep coming back to.
- **Tooling** — Burp Suite, browser DevTools, and the occasional custom script.

## Focus areas

- Web application security & the OWASP Top 10
- Broken authentication & access control
- Injection (SQLi, command, template)
- Request tampering and API abuse
